# Semi-Synthetic Plant-SVCA Benchmark Dataset
**Built on a real Stereo-seq Arabidopsis leaf section. Ground truth injected only at benchmark genes; 18,236 / 18,266 genes preserved byte-identical from the real slide.**

## Quick start
```python
import anndata as ad, pandas as pd
from scipy.sparse import load_npz

adata = ad.read_h5ad('semisim_plant_svca.h5ad')   # 665 spots x 18,266 genes
gt    = pd.read_csv('ground_truth.csv')           # 15 pairs with full annotations
A     = load_npz('neighbor_graph.npz')            # plant-aware adjacency

# Drop-in usage: pass adata.X straight into SpatialDM / COMMOT / your model.
# Sanity check:
print(adata.var['overwritten_by_sim'].sum(), "genes were regenerated by SVCA")
print(gt['role'].value_counts())                  # 5 true_lr, 5 confounder, 5 random
```

## Ground-truth design
- **5 TRUE pairs** (PlantPhoneDB, leaf-relevant)
  - EPFL9 -> ER       (mesophyll -> epidermis, sigma=3, gamma2=0.40)
  - CLE41 -> PXY      (vascular intra,         sigma=1, gamma2=0.45)
  - CLE9  -> BAM1     (guard -> epidermis,     sigma=2, gamma2=0.35)
  - CIF2  -> SGN3     (vascular intra,         sigma=2, gamma2=0.40)
  - PSK4  -> PSKR1    (spongy -> l. epidermis, sigma=5, gamma2=0.30)
- **5 co-localization confounders**: real tissue-specific NON-LR genes, same tissue, no kernel coupling -- specifically designed to fool naive co-expression methods
- **5 spatially-random pairs**: i.i.d. Gaussian latent signal -- sanity-check floor

## Key design facts
- The real Stereo-seq slide (665 spots, 18,266 genes, 6 cell types) is preserved as the spatial backbone.
- Only 30 / 18,266 columns (0.16% of the transcriptome) are overwritten with SVCA-generated counts.
- The other 18,236 columns are byte-identical to the original h5ad. Verified automatically.
- Per-spot library size is preserved (Pearson r = 0.96 vs the real slide).
- Bivariate Moran's I demonstrates that confounders > true_lr > random in raw spatial covariance -- naive correlation methods FAIL by design; this is the benchmark's central value.
